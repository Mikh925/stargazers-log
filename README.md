# stargazers-log
Проект «Дети Олимпа» для учеников 7 школы 2 класса (8–9 лет): у детей дефицит движения, секции платные и разбросаны по городу, нет единого места для разностороннего развития. Решение — занятия шестью видами спорта рядом со школой и в спортшколе «Темп»: хоккей, плавание, футбол, лёгкая атлетика, единоборства, шахматы.
